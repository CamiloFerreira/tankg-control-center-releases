# Tank-G Control Center — descargas

Editor de presets para la pedalera **M-VAVE Tank-G** en Windows, Linux y Android.
Este repositorio solo contiene los instaladores: las apps se actualizan solas desde aquí.

**[Descargar la última versión](https://github.com/CamiloFerreira/tankg-control-center-releases/releases/latest)**

| Sistema | Archivo |
|---|---|
| Windows 10/11 | `TankG-windows-x64.exe` |
| Linux x86_64 | `TankG-linux-x86_64` (`chmod +x` y ejecutar) |
| Android 6+ (teléfono o tablet) | `TankG-android.apk` — la pedalera se conecta con un adaptador USB-OTG |

Comprueba cada descarga con `SHA256SUMS`. Una vez instalada, la app avisa cuando hay una versión
nueva y se actualiza sola (en Android, el sistema pide confirmar la instalación).
